# m1cro.ai

**The AI Engineering Workspace**

One engineering workspace. Any model. Multiple agents.

m1cro.ai is a model-agnostic AI engineering platform. The initial release focuses on a trusted, local-first coding-agent runtime with BYOK and local model support. Hosted inference, the web workspace, browser/editor clients, and remote sandboxes follow behind stable runtime and security contracts.

## Principles

- Model freedom and local/BYOK independence
- Capability-aware routing
- Safe execution and explicit permissions
- One runtime across clients
- Portable sessions, skills and integrations
- Fast agent iteration with production-grade release checks

## Status
